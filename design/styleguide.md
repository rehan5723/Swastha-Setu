# SwasthaSetu — Auth UI Style Guide

Colors
- **Primary**: #0F52BA (Deep Sapphire)
- **Primary accent**: #3AA0FF
- **Background (right panel)**: gradient from #081229 → #001428
- **Card bg**: #FFFFFF
- **Muted text**: #516B8A

Typography
- **Primary**: Inter or system UI (Roboto fallback)
- **Headings**: 34px, 700 weight
- **Body**: 16px regular
- **UI labels**: 14px

Components
- `Input` — height 56px, border-radius 10px, subtle stroke #E6EEF8
- `Primary button` — height 60px, border-radius 12px, background `#0F52BA`, white text, 700 weight
- `Country selector` — compact left segment (120px) inside input showing `+91 ▾`

Layout
- Split-screen 60/40 (left card: 1152px, right art: 768px) on 1920×1080 canvas
- Left content centered vertically in a rounded card with 24px padding

Imagery
- Right panel uses layered glows, subtle lines and mesh to convey AI diagnostics (EKG, OCR, mesh)
- Avoid literal government logos — use stylized badge element for Ayushman Bharat reference

Accessibility
- Ensure button text contrast meets WCAG AA against the primary blue.
- Inputs must expose labels and focus outlines for keyboard users.

Export recommendations
- Export mockups at 2x (3840×2160) for high-res assets; provide PNG/JPEG for presentations.
